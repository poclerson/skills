# skills

Agent skills (Claude Code, and other agents that read `SKILL.md`).

| Skill | What it does |
|---|---|
| [arc-to-zen](skills/arc-to-zen/SKILL.md) | Migrate from Arc to Zen browser on macOS: spaces, pinned tabs, folders, favorites → Zen workspaces, folders, Essentials; plus history, passwords and extensions. |

## Install

```sh
npx skills add poclerson/skills
```

Or copy a folder from `skills/` into `~/.claude/skills/`.
